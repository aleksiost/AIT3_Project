## Ohjeet arvioijalle

* **Käynnistys:** Sovellus ei vaadi asennuksia tai palvelinta. Avaa `index.html` suoraan selaimessa (esim. Chrome tai Edge) ja paina käyttöliittymän **Scan**-painiketta.
* **API-avain:** Sovellus käyttää oletuksena NASA:n `DEMO_KEY`-avainta, jolla on kyselyrajoitus (30 kyselyä/tunti). Jos raja täyttyy arvioinnin aikana, `app.js`-tiedostoon voi vaihtaa oman ilmaisen NASA API -avaimen.
* **Yksilötyö:** Projekti on toteutettu itsenäisesti, joten kaikki suunnittelu, toteutus, testaus ja dokumentointi ovat omaa työtäni.
